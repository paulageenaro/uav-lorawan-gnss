# Documentación del Proyecto TFG

Esta carpeta centraliza toda la documentación técnica, arquitectónica y de formato para comprender la red LoRaWAN-UAV.

## Índice de Contenidos

- **`TFG_Implementacion_Resultados.md`**: El documento principal, estructurado académicamente para la memoria del TFG. Contiene el análisis de todo el desarrollo, flujo de datos, capturas y problemas resueltos.
- **`architecture.md`**: Explicación de los dos escenarios de arquitectura (básico e integrado) y sus diagramas de flujo.
- **`payload-format.md`**: Tablas detalladas sobre cómo se comprimen los bytes para enviarlos por aire (versión 12 bytes y versión 20 bytes).
- **`chirpstack-setup.md`**: Guía para la configuración inicial del Network Server.
- **`troubleshooting.md`**: Guía rápida de resolución de problemas experimentados durante el desarrollo (ej. desconexiones USB, visualización Grafana, etc.).
